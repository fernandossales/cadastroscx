Preencher o laudo no SIMIL

Do JSON exportado no celular para o Laudo de Avaliação › Unidade Isolada Construção, no computador.

Instalar (uma vez)

Arraste o botão abaixo para a barra de favoritos do Chrome/Edge:

Cadastro → SIMIL

Para as fotos seguirem sozinhas a cada recarga, instale também o script do Tampermonkey (opcional — sem ele, clique no favorito a cada foto).

Usar

  1. No SIMIL, abra Laudo Avaliação › Unidade Isolada Construção › Criar Laudo (ou abra o laudo pelo Pesquisar).
  2. Laudo novo: digite GIHAB, Cód. Solicitante, Ordenador, Ano e Complemento e clique em Gravar — isso libera as abas.
  3. Clique no favorito Cadastro → SIMIL. Abre um painel no canto da tela.
  4. Carregar JSON do celular → escolha o arquivo.
  5. Preencher campos. O painel lista o que não entrou (opção inexistente, campo bloqueado).
  6. Confira as abas e clique em Gravar no SIMIL.
  7. Enviar fotos. Cada foto recarrega a página; com o Tampermonkey o envio continua sozinho, sem ele clique no favorito de novo.

O preenchedor nunca clica em Gravar, Finalizar ou Cancelar — só em “Adicionar Foto”.

Automático com o Claude (escritório)

Com a skill simil-laudo instalada no Claude Code, basta pedir: “preencha no SIMIL o cadastro-xxx.json”. O Claude abre o laudo no seu Chrome (já logado), carrega o JSON, preenche, e envia as fotos — e pergunta antes de clicar em Gravar.

A skill fica em SKILL-simil-laudo.md neste repositório; copie para %USERPROFILE%\.claude\skills\simil-laudo\SKILL.md.

App de campo (iPhone)

  1. No Safari, abra o app › Compartilhar › Adicionar à Tela de Início (evita o iPhone apagar os dados e abre sem sinal).
  2. Permita a localização quando pedir. A coordenada é registrada sozinha ao abrir o cadastro.
  3. Fotos pela Câmera ou do Álbum: cada uma recebe data, coordenada e município–UF (do GPS da foto, se houver; senão, do aparelho).
  4. Exportar › “Salvar em Arquivos” (iCloud Drive), AirDrop ou e-mail. Carregar JSON abre um cadastro exportado em outro aparelho.
